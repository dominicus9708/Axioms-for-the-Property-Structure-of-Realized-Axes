# Release notes

## v1.0.0 — initial reproducibility package

- Mirrors the repository layout of the companion `Formation_Axiom_System` package.
- Uses Python standard library only and exact `Fraction` arithmetic.
- Implements finite PI and PII countermodels.
- Implements rank undefined/zero/one/two/three witnesses.
- Implements intrinsic normal, ambient normal, radical, nondegeneracy, and cyclic-closure checks for the displayed finite examples.
- Implements matrix-size/rank, equal-rank/property, equal-size/block, and scalar-collision obstructions.
- Adds deterministic JSON/CSV outputs, a verifier, unit tests, proof map, reproducibility guide, citation metadata, and GitHub Actions.

The package intentionally does not claim automated proofs of the manuscript's general set-theoretic theorems.
